# `@layerzerolabs/nexus-evm-contracts`

Nexus top-level EVM contracts.

## Build

Compile with the options specified in `hardhat.config.js`.

## Deployment

Deploy upgradeable instances behind `@layerzerolabs/proxy-v5-6-evm-contracts` `TransparentUpgradeableProxy2Step` (not OpenZeppelin's stock `TransparentUpgradeableProxy`).
